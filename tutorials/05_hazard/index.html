    5. Global flood hazard (GLOFAS)¶

    Alongside the historic flood maps, hazard(...) queries the modelled CEMS-GLOFAS flood-hazard maps by return period (the depth expected on average once every N years). Hazard catalogues are just as actionable as historic ones: the same .download(), .stats(), .plot(), and .explore() all work.

    This tutorial downloads real hazard tiles, so it needs network access.

    In [1]:
    Copied! 
    from pathlib import Path

import euroflood as ef

ef.settings.output_dir = Path("out")
    from pathlib import Path import euroflood as ef ef.settings.output_dir = Path("out")

    Query the 100- and 500-year return periods for Zutphen. One row per return period (supported: 10, 20, 50, 75, 100, 200, 500):

    In [2]:
    Copied! 
    haz = ef.hazard("Zutphen, Netherlands", return_period=[100, 500], shape="bbox")
haz

    Download and measure them. GLOFAS depth is already in metres and is reported as-is (EFAS historic depth is centimetres; the scale is chosen automatically per catalogue).

    In [4]:
    Copied! 
    haz = haz.download()
haz.stats()
    haz = haz.download() haz.stats()

    Static and interactive depth maps¶

    Render the 100-year hazard depth as a static image…

    In [5]:
    Copied! 
    rp100 = haz[haz["return_period"] == 100]
rp100.plot(depth=True)
    rp100 = haz[haz["return_period"] == 100] rp100.plot(depth=True)
    Out[5]:
    <Axes: title={'center': 'Flood depth: hazard_RP100_8277ba1c'}>

    …and as an interactive folium overlay you can pan and zoom:

    In [6]:
    Copied! 
    rp100.explore(depth=True, tiles="grayscale")
    rp100.explore(depth=True, tiles="grayscale")
    Out[6]:
    Make this Notebook Trusted to load map: File -> Trust Notebook

    The recurrence/footprint views are historic-only (hazard has no event index), so a hazard .explore() without depth= shows a context map of the queried area:
